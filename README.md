### <a id="ex-1"></a>پاسخ تمرین 1:

1. تخم‌مرغ، روغن یا کره، نمک و فلفل را آماده کن.
2. تخم‌مرغ‌ها را در یک کاسه بشکن.
3. نمک و فلفل اضافه کن و تخم‌مرغ‌ها را خوب هم بزن.
4. ماهیتابه را روی حرارت متوسط بگذار و روغن یا کره را داخل آن بریز.
5. وقتی روغن داغ شد، مخلوط تخم‌مرغ را در ماهیتابه بریز.
6. صبر کن تا زیر املت بپزد.
7. املت را از وسط تا کن یا برگردان.
8. چند لحظه صبر کن تا کاملاً بپزد، سپس آن را داخل بشقاب بکش.

# --------------------------------------------------
# a = 2 + 3 * 4

#   2 + 12 = 14
# نتیجه نهایی: 14
# توضیح: استفاده از پرانتز (2 + (3 * 4)) خوانایی را کمی بهتر می‌کند.

# b = (2 + 3) * 4
# بالاترین عملگر: پرانتز (سپس *)

#   2 + 3 = 5
#   5 * 4 = 20
# نتیجه نهایی: 20
# توضیح: پرانتز از قبل وجود دارد و عبارت کاملاً خوانا است.

# --------------------------------------------------
# c = 2 ** 3 * 2 + 1
# بالاترین عملگر: **
# مرحله‌به‌مرحله:
#   2 ** 3 = 8
#   8 * 2 = 16
#   16 + 1 = 17
# نتیجه نهایی: 17
# توضیح: نوشتن به صورت ((2 ** 3) * 2) + 1 خوانایی را بهتر می‌کند.

# --------------------------------------------------
# d = -2 ** 2
# بالاترین عملگر: **
# مرحله‌به‌مرحله:
#   2 ** 2 = 4

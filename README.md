### <a id="ex-33"></a>پاسخ تمرین 33:

```python

# اولویت با ضرب است: 3 * 4 = 12

# 2

# اول پرانتز: 2 + 3 = 5
# سپس ضرب: 5 * 4 = 20

# 3
```

```py
    elif guess < secret_number:
        return "Too low"
```

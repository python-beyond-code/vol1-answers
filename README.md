### <a id="ex-1"></a>پاسخ تمرین 1:

1. تخم‌مرغ، روغن یا کره، نمک و فلفل را آماده کن.

### <a id="ex-37"></a>پاسخ تمرین 37:

```python
# --------------------------------------------------
# a = 2 + 3 * 4
# بالاترین عملگر: *
# مرحله‌به‌مرحله:
#   3 * 4 = 12
#   2 + 12 = 14
# نتیجه نهایی: 14
# توضیح: استفاده از پرانتز (2 + (3 * 4)) خوانایی را کمی بهتر می‌کند.

# --------------------------------------------------
# b = (2 + 3) * 4
# بالاترین عملگر: پرانتز (سپس *)
# مرحله‌به‌مرحله:
#   2 + 3 = 5
#   5 * 4 = 20
# نتیجه نهایی: 20
# توضیح: پرانتز از قبل وجود دارد و عبارت کاملاً خوانا است.

# --------------------------------------------------
# c = 2 ** 3 * 2 + 1
# بالاترین عملگر: **
# مرحله‌به‌مرحله:
#   2 ** 3 = 8
#   8 * 2 = 16
#   16 + 1 = 17
# نتیجه نهایی: 17
# توضیح: نوشتن به صورت ((2 ** 3) * 2) + 1 خوانایی را بهتر می‌کند.

# --------------------------------------------------
# d = -2 ** 2
# بالاترین عملگر: **
# مرحله‌به‌مرحله:
#   2 ** 2 = 4
#   -4
# نتیجه نهایی: -4
# توضیح: چون اولویت ** از منفی یکانی بیشتر است، نوشتن -(2 ** 2) خوانایی را بسیار بهتر می‌کند.

# --------------------------------------------------
# e = (-2) ** 2
# بالاترین عملگر: پرانتز (سپس **)
# مرحله‌به‌مرحله:
#   -2
#   (-2) ** 2 = 4
# نتیجه نهایی: 4
# توضیح: پرانتز از قبل وجود دارد و عبارت خوانا است.

# --------------------------------------------------
# f = 20 / 5 * 2
# بالاترین عملگرها: / و * (اولویت یکسان، از چپ به راست)
# مرحله‌به‌مرحله:
#   20 / 5 = 4.0
#   4.0 * 2 = 8.0
# نتیجه نهایی: 8.0
# توضیح: نوشتن (20 / 5) * 2 خوانایی را بهتر می‌کند.

# --------------------------------------------------
# g = 20 - 5 + 2
# بالاترین عملگرها: - و + (اولویت یکسان، از چپ به راست)
# مرحله‌به‌مرحله:
#   20 - 5 = 15
#   15 + 2 = 17
# نتیجه نهایی: 17
# توضیح: نوشتن (20 - 5) + 2 خوانایی را کمی بهتر می‌کند.

# --------------------------------------------------
# h = True or False and False
# بالاترین عملگر: and
# مرحله‌به‌مرحله:
#   False and False = False
#   True or False = True
# نتیجه نهایی: True
# توضیح: نوشتن True or (False and False) خوانایی را بسیار بهتر می‌کند.

# --------------------------------------------------
# i = (True or False) and False
# بالاترین عملگر: پرانتز (سپس and)
# مرحله‌به‌مرحله:
#   True or False = True
#   True and False = False
# نتیجه نهایی: False
# توضیح: پرانتز از قبل وجود دارد و عبارت خوانا است.

# --------------------------------------------------
# j = 10 + 2 * 3 ** 2 > 25 and 20 % 3 == 2
# بالاترین عملگر: **
# مرحله‌به‌مرحله:
#   3 ** 2 = 9
#   2 * 9 = 18
#   10 + 18 = 28
#   28 > 25 → True
#   20 % 3 = 2
#   2 == 2 → True
#   True and True → True
# نتیجه نهایی: True
# توضیح: نوشتن به صورت ((10 + (2 * (3 ** 2))) > 25) and ((20 % 3) == 2)
#          ترتیب اجرا را کاملاً مشخص و خوانایی را بسیار بهتر می‌کند.
```
